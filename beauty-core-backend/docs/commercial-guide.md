# Manual Comercial — Beauty Core 1.0

## 1. O que é o Beauty Core
Beauty Core 1.0 é uma plataforma SaaS white-label para negócios de estética, beleza e serviços recorrentes.

Ela oferece uma base tecnológica profissional para gestão de clientes, agenda, serviços, financeiro, pacotes, fidelidade, comunicação, arquivos, relatórios e operação multiempresa.

## 2. Público-Alvo
- Clínicas de estética.
- Salões de beleza.
- Barbearias premium.
- Profissionais autônomos de beleza.
- Redes com múltiplas unidades.
- Franquias de estética.
- Negócios que vendem pacotes e recorrência.

## 3. Diferenciais
- Plataforma white-label.
- Multiempresa forte.
- Portal cliente.
- Segurança enterprise.
- Refresh token e sessões.
- Uploads privados.
- Automação com filas.
- Scheduler enterprise.
- Observabilidade.
- Backup, restore e DR.
- LGPD.
- CI/CD.

## 4. Proposta de Valor
O Beauty Core permite entregar uma solução profissional sob marca do cliente, com base técnica robusta e capacidade de personalização comercial.

A venda não deve ser posicionada como site simples, mas como sistema de operação, retenção, relacionamento e gestão.

## 5. Casos de Uso
- Clínica quer organizar agenda e clientes.
- Espaço de beleza quer vender pacotes.
- Profissional quer fidelizar clientes.
- Rede quer controlar múltiplas unidades.
- Empresa quer portal cliente personalizado.
- Negócio quer campanhas e comunicação recorrente.

## 6. Vantagens Competitivas
- Base proprietária reutilizável.
- Arquitetura pronta para escala.
- Segurança como argumento comercial.
- LGPD como diferencial.
- White-label para ticket maior.
- Possibilidade de recorrência mensal.
- Evolução futura para app e IA.

## 7. Posicionamento Premium
O Beauty Core deve ser vendido como plataforma personalizada de gestão, não como template barato.

Argumentos premium: segurança, automação, portal cliente, dados protegidos, backup, operação profissional e personalização de marca.

## 8. Estratégia SaaS
Modelos possíveis: setup inicial, mensalidade recorrente, plano por recursos, plano por unidade, plano por volume e customizações pagas.

A recorrência deve cobrir hospedagem, suporte, manutenção, backup, monitoramento e evolução.

## 9. Oferta Comercial
Oferta recomendada: implantação white-label com painel, portal cliente, gestão operacional, automações, segurança, backup e suporte técnico.

Adicionar opcionais: app mobile, WhatsApp oficial, gateway de pagamento, dashboards avançados, IA e integrações.

## 10. Conclusão
O Beauty Core 1.0 possui base técnica e narrativa comercial para ser vendido como solução SaaS premium para estética e beleza.
